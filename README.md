# Rakshanet

**Offline Disaster Communication and AI Rescue System**

SignalRescue AI (RakshaNet) is an offline-first disaster communication system that turns nearby smartphones into a temporary emergency mesh network. When cellular networks and the Internet fail during natural disasters, RakshaNet enables survivors to communicate, send multi-hop SOS distress signals, share coordinates, and relay critical data to emergency rescue authorities.

## Key Features

- **Offline Device-to-Device Mesh:** BLE and Wi-Fi Direct peer-to-peer communication.
- **Store-and-Forward Delay-Tolerant Networking (DTN):** Multi-hop opportunistic relay from phone to phone until reaching an Internet gateway.
- **Tactile Emergency SOS:** Instant distress beaconing with location fallback states and payload persistence.
- **Lightweight On-Device AI:** Compressed triage engine for offline emergency classification and survival runbooks.
- **Command Center & Incident Clustering:** Spatial clustering (DBSCAN), communication-gap anomaly detection, and automated rescue dispatch optimization.
